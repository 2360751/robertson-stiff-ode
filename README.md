# Numerical Solution of the Robertson Stiff ODE System

**Project 1 — Numerical Analysis of ODEs and PDEs (Weeks 1–4)**
Topic ③ from the Problem Pack: *Chemical kinetics — the Robertson problem*, a classic
stiff benchmark, used to answer one mathematical question:

> **How does stiffness, quantified by the frozen-Jacobian eigenvalues of the Robertson
> system, translate into a practical step-size restriction for explicit methods — and
> what, exactly, does an implicit method pay for the same accuracy?**

## Methods implemented (all from scratch)

* Explicit Euler (order 1)
* Classical RK4 (order 4)
* Implicit (backward) Euler with Newton's iteration on the stage equation,
  analytic Jacobian, Newton tolerance 1e-10
* Adaptive RK4 with step-doubling local-error estimation, componentwise
  tolerance `tol*|y_i| + atol`, a problem-aware positivity veto, and an
  empirical stability cap learned from rejected steps

Validation oracle (built by ourselves, per the Project Brief §2):

1. `scipy.integrate.solve_ivp` Radau, `rtol=1e-12`, per-component `atol`,
   repeated with tolerances tightened ~45x; only surviving digits reported.
2. Invariant plane `y1+y2+y3 = 1` and componentwise positivity tracked for
   every method.
3. Cross-checks against the values printed in the Problem Pack
   (y(40) ≈ (0.7158271, 9.1855e-6, 0.2841637); stiffness ratio ≈
   3.0e3 / 5.4e3 / 1.58e5 at t = 1e-4 / 1e-2 / 40).
